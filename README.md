# vibe.music

  .минималистичный пиксельный музыкальный плеер с живым визуализатором и эквалайзером

  ## возможности _（*＾-＾*）_

  .воспроизведение локальных треков - mp3, wav, ogg и другие форматы

  .живой визуализатор - 40 анимированных баров, реагирующих на музыку

  .6-полосный эквалайзер - точная настройка звука (60hz - 10khz)

  .автосохранение плейлиста - ваши треки сохраняются в браузере

  .drag & drop - просто перетащите файлы в окно

  .пиксельный дизайн - ретро-стиль с плавными анимациями

  .скрываемые настройки - чистый интерфейс без лишнего

  ## использование _(‾◡◝)_

  .откройте плеер в браузере

  .перетащите музыкальные файлы или нажмите выбрать файлы

  .наслаждайтесь музыкой

  ## локальный запуск _(☆▽☆)_

  .откройте index.html в браузере - никаких зависимостей не требуется

  ## управление _( ﾉ ﾟｰﾟ)ﾉ_

  .space / click - воспроизведение / пауза

  .стрелки - предыдущий / следующий трек

  .click на прогресс-бар - перемотка

  .кнопка настройки - громкость и эквалайзер

  ## технологии _(. ❛ ᴗ ❛.)_

  .чистый html / css / javascript

  .web audio api для визуализатора и эквалайзера

  .localstorage для сохранения плейлистов

  .пиксельный шрифт press start 2p

  ## особенности _(☆▽☆)_

  .работает полностью оффлайн

  .все треки обрабатываются локально в браузере

  .никаких внешних зависимостей кроме google fonts
